# 題材企画: 文字数をUTF-8バイト添字として使う

| 項目 | 内容 |
| --- | --- |
| 対象 | Rust標準ライブラリの`str`、UTF-8、文字列スライス |
| 難易度 | 実践・上級。文字数とバイト数の相違、UTF-8境界、パニックを分けて観測する |
| 契約 | `障害対応手順`を最大5文字へ省略すると`障害対応手…`を返し、パニックしない |
| 再現境界 | 公開関数`abbreviate_for_log`をユニットテストから呼ぶ |
| 直接結果 | 返却した省略文字列 |
| 別の観測 | `chars().count()`、`len()`、`is_char_boundary()`のログとGDBのローカル値 |
| バグ状態 | `e43f633`。文字数を`&text[..max_chars]`のバイト添字として使う |
| 修正状態 | `e4a5ada`。`chars().take(max_chars)`でUnicodeスカラー値を取り出す |

## 競合仮説

| 仮説 | 観測による判定 |
| --- | --- |
| 入力が期待より短い | `chars().count()`は6であり、最大文字数5より大きいので除外 |
| 範囲が文字境界にない | `is_char_boundary(5)`が`false`であり、支持 |
| 省略記号の結合が失敗する | スライス作成時にパニックしており、結合前のため除外 |
